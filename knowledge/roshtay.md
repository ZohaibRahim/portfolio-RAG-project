# Roshtay — Web & AI Solutions

## Overview

Roshtay is a web and AI solutions studio founded in 2026 to design, build, and deploy client-facing digital products. The studio uses a structured AI-assisted delivery workflow that moves from research and design through implementation and deployment.

Current documented state:

- Founder-led web and AI solutions studio
- **3 production client demo applications deployed**
- Client-facing website: `roshtay.com`
- Projects delivered through a repeatable multi-tool workflow
- Git-based development and Vercel deployment

## Purpose

Roshtay was created to turn business ideas and client requirements into working digital products without treating AI tools as a replacement for engineering judgment.

The workflow separates research, design, interface generation, implementation, version control, and deployment so each stage has a clear purpose.

## Engineering Approach

### 1. Start from the business problem

The process begins with understanding what needs to be solved rather than immediately generating code.

### 2. Separate research from implementation

Research and discovery are completed before implementation so technical choices can be tied back to the problem and requirements.

### 3. Use AI tools for specific stages

Different AI tools are used for different jobs rather than relying on one tool for the entire development process.

### 4. Keep version control in the loop

GitHub is part of the delivery workflow rather than an afterthought, allowing deployed applications to remain tied to tracked source code.

### 5. Deploy working applications

The output is intended to be a usable client-facing application rather than only a mock-up or prototype screenshot.
