## Overview

A single-page static portfolio with:

- **Hero** with animated tagline (respects `prefers-reduced-motion`), résumé + primary CTA, headshot card with metric chips, floating credibility badges.
- **Org credibility strip** — PHSA, AKU, UNBC, Roshtay, JDC WEST with hover-reveal descriptions (always-visible on mobile).
- **Project Portfolio** — 3 tabs (Data & BI / Business Systems / Software) with 15 projects total. Each opens an accessible modal with an image gallery, results, contributions, tech stack, links, and — where relevant — a data-note explaining any illustrative/confidential figures.
- **Professional Experience** — chronological timeline (Roshtay founder → AKU intern → PHSA co-op → JDC delegate → UNBC roles → prior tech roles).
- **About Me** — 3 stat cards (Education, Location, Availability), 4-tab knowledge browser (Skills, Education, Certificates, Leadership), and a "Self-Directed by Design" 6-step methodology strip.
- **JDC West 2026 first-place callout** with team photo, evidence links, and "UNBC's first BTM podium in 19 years" positioning.
- **Contact CTA** with availability pills and dual buttons (email + LinkedIn).
- **Footer** with brand mark, tagline, navigation, and connect links.
- **Custom 404 page** matching the brand system.
- **Dark mode** with first-paint sync (no flash), OS preference detection, localStorage override.

## Tech stack

| Layer | Choice | Why |
|---|---|---|
| Markup | Vanilla HTML5 (single `index.html` + `404.html`) | Zero framework tax, ideal for a portfolio scale |
| Styling | [Tailwind CSS 3.4](https://tailwindcss.com) + `@tailwindcss/forms`, `@tailwindcss/container-queries` | Compiled once via CLI → ~44 KB minified `styles.css` |
| Custom CSS | Inline `<style>` block for scoped rules (org tags, project grid, gallery, iOS scroll fixes, cert-icon masks) | Faster than authoring in JIT-Tailwind |
| Icons | [Material Symbols Outlined](https://fonts.google.com/icons) via Google Fonts (single weight, non-variable) + one masked PNG for the Azure cert badge | Balance of coverage vs weight |
| Fonts | Inter (body), Manrope (headline), IBM Plex Mono (technical labels) | Loaded via Google Fonts with `preconnect` + `display=swap` |
| JavaScript | Vanilla ES2020 IIFE | Tab switching, modal, focus trap, scroll-spy, typewriter, theme toggle, image gallery, mobile drawer |
| Build | `npm run build` (Tailwind CLI) | Single-command CSS generation |
| Hosting | [Vercel](https://vercel.com) — static site, `outputDirectory: "."` | Serves from repo root; runs `npm run build` on each deploy |

No React, no Vue, no bundler, no PostCSS pipeline beyond Tailwind's built-in one. Total shipped JS is a few kilobytes of hand-written vanilla.

## Getting started

**Requirements:** Node.js 18+, Python 3.9+ (only if you need to regenerate images).

```bash
# clone
git clone <your-repo-url>
cd "Personal Website"

# install Tailwind + plugins
npm install

# build styles.css once
npm run build

# or watch for changes during development
npm run watch

# serve locally (any static server works)
python -m http.server 5500
# → open http://localhost:5500
```

That's the entire dev loop. There's no framework, no HMR, no dev server. Edit `index.html`, refresh the browser.

## Design system

### Colors — see `tailwind.config.js` and `index.html:145–170`

**Primary blue** (`#2563EB` light / `#60A5FA` dark) drives every accent — the bracket mark, tab active state, links, CTAs, chips.

**Org brand colors** — each institution has its own CSS variable so headings in About + org strip stay on-brand:

| Org | Light | Dark |
|---|---|---|
| PHSA | `#176B3A` | `#2ED498` |
| AKU  | `#00843D` | `#3FDA7A` |
| UNBC | `#035642` | `#F5D64C` (gold — differentiates from other greens) |
| Roshtay | `#246F91` | `#5AC8E8` |
| JDC WEST | `#263F7D` | `#7DA5F7` |

### Typography

- **Manrope** — hero, page headlines, card headlines, section titles
- **Inter** — body copy, forms, most UI text
- **IBM Plex Mono** — kicker labels, uppercase tracked-widest chips ("EXPERIENCE AND WORK ASSOCIATED WITH", "DATA, BI & ANALYTICS", timeline dates, technical labels)

### Spacing tokens

- `--nav-h: 5rem` — single source of truth for the fixed nav height; drives `.pt-nav`, `.h-nav`, `section[id] { scroll-margin-top }`
- `section-v-mobile: 48px`, `section-v-desktop: 72px` — section vertical padding
- `container-max: 1240px` — max content width
- `gutter-mobile: 18px`, `gutter-desktop: 24px` — horizontal edge padding

### Component patterns

- `.enterprise-card` — the standard bordered card look (used everywhere from project cards to modal side panels to cert tiles)
- `.card-hover-lift` — cursor pointer + hover shadow used for clickable cards
- `.project-grid` — flex-wrap layout that centers orphan rows (avoids the empty-third-column look when a tab has 5 cards)
- `.org-strip` — 2-col mobile / natural-wrap desktop for org credibility strip
- `.skill-tag`, `.skill-tag-data`, `.skill-tag-digital`, `.skill-tag-software` — color-coded pills matching each discipline
- `.certificate-icon-azure` — CSS-masked image so the Azure PNG inherits the primary color in both themes
- `.hero-decor` — floating badges tagged `pointer-events: none` so touches pass through to the body scroller (iOS scroll fix)

## Accessibility

The site targets **WCAG 2.2 AA**:

- **Skip link** to `#main` on Tab focus
- **Semantic landmarks** — `<nav>`, `<main>`, `<section id="...">`, `<footer>`
- **Focus rings** preserved via `focus:outline-none focus-visible:*` (never removed without a replacement)
- **Modals** — `role="dialog" aria-modal="true"` with focus trap, `Escape` to close, backdrop-click to close, `aria-labelledby` pointing to the modal title `<h2>`
- **Tabs** — `role="tablist" / role="tab" / role="tabpanel"` with correct `aria-selected` and `aria-hidden` toggling
- **Mobile drawer** — same dialog pattern as modals
- **Prefers-reduced-motion** — typewriter falls back to a 3.5-s interval instant swap, no character-by-character animation
- **iOS Safari touch fixes** — `body { touch-action: pan-y; overscroll-behavior-y: contain }` + `#hero` uses `overflow-x: clip` (not `hidden`) to avoid the implicit `overflow-y: auto` that creates a phantom inner scrollbar
- **Alt text** on every image (via `alt=` or `aria-label` on decorative-icon spans)
- **Color contrast** — all body text passes AA against both light + dark backgrounds

## Performance

- **Static Tailwind build** (~44 KB minified) — not the runtime CDN JIT (which was ~300 KB gzipped)
- **First-paint dark-mode script** — inline in `<head>` runs before body paints, syncs `.dark` class from localStorage or OS preference; no theme flash
- **Hero LCP image** — `fetchpriority="high" decoding="async"` + explicit `width`/`height` to prevent CLS
- **`loading="lazy"`** on all below-the-fold images (JDC team photo, Azure cert icon, project card previews)
- **Preconnect hints** for `fonts.googleapis.com` + `fonts.gstatic.com`
- **Material Symbols font** — reduced from full variable range (`wght,FILL@100..700,0..1`) to single weight (`wght,FILL@400,0..1`) — meaningful bytes saved
- **Compressed images** — every project screenshot is a `.jpg` at quality 82–85, max 1400 px wide (see `scripts/optimize_assets.py`)
- **`.vercelignore`** keeps 5+ MB of source PNGs, docx files, and dev scripts out of the deploy

## Deploy (Vercel)

`vercel.json` at the repo root drives everything:

```json
{
  "$schema": "https://openapi.vercel.sh/vercel.json",
  "buildCommand": "npm run build",
  "outputDirectory": ".",
  "cleanUrls": true,
  "trailingSlash": false
}
```

On every push, Vercel:
1. Runs `npm install`
2. Runs `npm run build` → generates fresh `styles.css` from the current HTML classes
3. Serves the repo root as static files
4. Enforces clean URLs (`/about` not `/about.html`) and consistent trailing-slash behavior

**Custom domain** — configured in Vercel dashboard (currently `zohaibrahim.vercel.app`, but the canonical `<link>` and JSON-LD point here so a custom domain swap only needs 2 lines of HTML changed).

## Asset pipeline

Two Python scripts in `scripts/` handle content freshness:

### `optimize_assets.py`

Idempotent — safe to re-run. It:

1. Resizes and re-encodes every project screenshot to a controlled max width + JPEG quality
2. Crops the Azure cert icon to its visible bbox (removes transparent padding)
3. Regenerates `apple-touch-icon.png` (180×180 dark tile with `[ ZR ]` monogram)
4. Regenerates `og-card.png` (1200×630 social share with `[ ZR ]` + name + tagline + pills + URL)

Add new project images to the `tasks` list at the bottom of `main()` and run:

```bash
python scripts/optimize_assets.py
```

### `dump_docs.py`

Dumps the master résumé + link doc + experience doc to plain text. Used to **verify every metric on the site traces back to a signed-off source** — a self-imposed accuracy rule (see `CLAUDE.md`).

```bash
python scripts/dump_docs.py > scripts/_docs_dump.txt
```

Then grep for any metric on the site — if it's not in the master résumé, it doesn't ship.

### Ad-hoc PDF → image (Gradified pitch deck)

The Gradified deck was converted from PDF using **PyMuPDF**:

```bash
python -m pip install PyMuPDF
python -c "
import fitz
from PIL import Image
doc = fitz.open('Assets/Images/_source/Gradified/Linkedin Post.pdf')
for i, page in enumerate(doc):
    pix = page.get_pixmap(matrix=fitz.Matrix(2, 2))
    im = Image.frombytes('RGB', [pix.width, pix.height], pix.samples)
    im.thumbnail((1400, 1400), Image.LANCZOS)
    im.save(f'Assets/Images/Gradified/Gradified_LinkedIn_{i+1}.jpg', 'JPEG', quality=85, optimize=True)
"
```

## Design decisions

**Why single-file HTML instead of a framework?** — A portfolio scales to maybe 20 sections and 30 modal entries. Framework overhead (bundler, hydration, build config) buys nothing at this scale. Static HTML loads in <100 ms on cable.

**Why Tailwind instead of a hand-written CSS system?** — Utility classes eliminate the "invent a name for this margin" tax. The generated CSS is smaller than the equivalent hand-authored system because unused utilities get purged.

**Why the `[ ZR ]` bracket monogram?** — The bracket motif reads as "code / systems" — perfect for an IT portfolio. It's typographically light (no separate SVG needed for most surfaces), scales cleanly from 12 px favicon to a 30 px footer lockup, and the same "Building Better Systems" tagline appears both in the mark's associated typography and as the first phrase of the hero typewriter — brand continuity built in.

**Why duplicate courses across tabs?** — A recruiter viewing only the "Software" tab shouldn't miss that you took Applied ML or Data Mining. A recruiter on the "Data" tab shouldn't miss that you took Data Structures and Algorithm Analysis. Duplication is cheaper than a filter UI, and each tab becomes a self-contained pitch.

**Why hover-reveal descriptions on org strip (desktop) vs always-visible (mobile)?** — Mobile has no hover. Users would never learn what "AKU" or "PHSA" stand for. Below `md`, the full org name always shows under each abbreviation.

**Why CSS mask for the Azure icon?** — One PNG asset, but it needs to be different colors in light vs dark mode. `background-color` + `mask-image` gives the icon `currentColor`-like theming for free. Same-file, zero-JS solution.

**Why `overflow-x: clip` instead of `overflow-x: hidden`?** — Per the CSS spec, setting one axis to `hidden` implicitly sets the other to `auto` — so `overflow-x: hidden` on the hero was silently creating a second vertical scrollbar inside the hero on mobile. `clip` avoids that trap.

**Why illustrative / anonymized data notes on PHSA modals?** — Real PHSA figures are confidential. Rather than remove the screenshot (which leaves a placeholder), the site shows the actual UI with a clear amber note explaining that values are illustrative. This preserves the visual proof of the work while respecting the NDA.

**Why gallery vs single image in modals?** — Some projects (JobTrackr, Power BI Resume, Gradified pitch, Stock Market Dashboard) have multiple meaningful views. A recruiter clicking "case study" wants to browse, not scroll a single hero shot.
